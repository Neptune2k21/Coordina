Coordina is a React and .NET workspace product. The app owns authentication,
workspace tenancy, project boards, and the collaboration surface. This
documentation lives outside the web bundle so product code stays focused on the
actual application.

## Architecture at a glance

| Area | Stack |
| --- | --- |
| Web | React 19, Vite, TypeScript, Tailwind CSS |
| API | ASP.NET Core 9 minimal APIs, EF Core, PostgreSQL |
| Native engine | C++20 graph engine loaded by the API |
| API docs | OpenAPI JSON plus Scalar for local testing |
| Product docs | Mintlify MDX in this `docs/` directory |
